4. Theoretical Discussion & Homework Questions

1. Comparison: Toy ECC Scheme vs. Caesar Cipher

Property Toy ECC (ECIES / ElGamal) Caesar Cipher
Cryptography Type Asymmetric (Public-Key): Separate encryption key (QB) and decryption key (kB). Symmetric: Single secret shift key (k) shared by both sender and receiver.
Key Space Size Group order of the curve: N = 18 (Toy) vs. ≈ 2256 (Real secp256k1). Modulo 26: exactly 26 possible keys (k ∈ {0, \dots, 25}).
Mathematical Procedure Non-linear group scalar multiplication over finite field (Q = kG), followed by Diffie-Hellman mask addition. Linear monoalphabetic substitution: each letter x → (x + k) \bmod 26.
Statistical Properties Eliminates letter frequencies when paired with ephemeral keys (r changes per message). Completely preserves letter frequencies: The ciphertext is simply a shifted copy of the plaintext distribution.

2. Statistical Attack (Caesar) vs. Algebraic Attack (Toy ECC)

• The Caesar Attack is Empirical & Language-Dependent: It requires redundancy in the plaintext (English language rules) and a sufficiently large sample size. If the plaintext is random bytes or compressed data, statistical cryptanalysis fails completely.
• The Toy ECC Attack is Purely Algebraic & Exact: It exploits the mathematical definition of the group. It does not require any prior knowledge of the message, language, or sample size. The attacker tests integers k = 1, 2, \dots until kG = QB.

3. Why the Attack Fails on Real-World secp256k1

In Ethereum's production secp256k1 curve: $$\text{Key Space } N \approx 2^{256} \approx 1.15 \times 10^{77}$$ Even using Pollard’s Rho algorithm (which finds discrete logs in O(\sqrt{N}) operations), cracking the private key requires 2^{128} \approx 3.4 \times 10^{38} operations. If all supercomputers on Earth performed one billion scalar multiplications per second, it would still take over 10^{21} years (millions of times the age of the universe) to crack a single private key.

4. Weaknesses: Restricted Key Space vs. Toy Scheme Design

• Vulnerability from Restricted Key Space: A key space of N = 18 is trivial to exhaust. An adversary can test all 18 keys in less than 1 millisecond.
• Vulnerabilities in the Toy Design Itself:
1. Lack of Authenticated Encryption (Malleability): Our toy scheme does not include a Message Authentication Code (MAC) or AEAD wrapper. An active attacker can tamper with ciphertext bits in transit.
2. Small Field Wrap-Around: Because p = 17, shared secret coordinates S_x take values in [0, 16], which is smaller than the 26-letter English alphabet, introducing modular modulo-bias if used as a raw Caesar shift.
