Exercise 1 — Riemann and Lebesgue Numerical Integration

While the Riemann integral partitions the domain of a function into vertical strips, the Lebesgue integral partitions the range of function values into horizontal slabs and weights them by the measure of their preimages in the domain:

Riemann Sum: Partition domain [a, b] into N intervals:
IR = ∑i=0N−1 f(xi*) Δxi, where Δxi = xi+1 − xi.

Lebesgue Sum: Partition range [ymin, ymax] into M intervals [yj, yj+1):
IL = ∑j=0M−1 yj* · μ(Ej), where Ej = {x ∈ [a, b] : f(x) ∈ [yj, yj+1)} and μ(Ej) is the Lebesgue measure of the preimage set.

Theoretical Discussion & Mathematical Foundations

1. Why Does the Normal CDF Lack an Elementary Antiderivative? (Liouville’s Theorem)

The function f(t) = e−t²/2 is continuous everywhere, so by the Fundamental Theorem of Calculus, its antiderivative exists. However, it cannot be written as an elementary function (a finite combination of polynomials, exponentials, logarithms, trigonometric functions, and root extractions).

Liouville’s Theorem on Integration in Finite Terms (1835):
Let K be a differential field and let f ∈ K. If an antiderivative ∫ f dx is elementary over K, it must be expressible in the form:
∫ f dx = g0 + ∑i=1k ci ln(gi), where g0, g1, &dots;, gk belong to the base differential field K and ci are constants.

For functions of the form f(t) = p(t) eq(t) where p, q are rational functions: an elementary antiderivative exists if and only if there exists a rational function r(t) satisfying the differential equation:
r'(t) + r(t) · q'(t) = p(t).
For the Gaussian integrand q(t) = −t²/2 and p(t) = 1, the equation becomes r'(t) − t · r(t) = 1. Degree analysis demonstrates that no polynomial or rational function r(t) can satisfy this relationship. Hence, by Liouville’s Theorem (formalized algorithmically by Robert Risch in 1969), the normal CDF is provably non-elementary.

2. The Role of Special Functions: The Error Function (erf)

Because no elementary antiderivative exists, mathematicians standardized the Error Function:
erf(z) = (2 / √π) ∫0z e−u² du.
Through the variable substitution u = t / √2 (so dt = √2 du), the normal CDF is analytically represented in closed form as:
Φ(x) = 1/2 [ 1 + erf(x / √2) ] = 1/2 erfc(−x / √2).
Introducing erf(z) provides an exact analytical identity for derivations, calculus, and differential equations, yet evaluating erf(z) on a digital computer still fundamentally requires numerical approximation.

3. Comparison of Numerical Evaluation Approaches for Φ(x)

  • Power Series Expansion: Expanding e−u² via Taylor series yields erf(z) = (2/√π) ∑n=0∞ (−1)n z2n+1 / (n! (2n+1)). While it converges everywhere on ℂ, for |x| > 3 the alternating signs cause severe catastrophic cancellation and slow convergence, rendering it impractical for large tails.
  • Numerical Quadrature (Simpson's / Trapezoidal): Truncating the lower bound to −8 (since Φ(−8) ≈ 6.6 × 10−16) and using composite Simpson's rule is highly flexible, but requires hundreds of function evaluations per call (O(N) complexity).
  • Rational Chebyshev Approximations (Hart / Cody / A&S): Production software libraries (e.g., Python's `scipy.stats.norm`, C++ `std::erf`, and glibc) use rational minimax polynomials. Dividing two low-degree polynomials (e.g. degree 6 over degree 6) provides double-precision accuracy (ε < 10−15) in a fraction of a microsecond using O(1) CPU operations.

4. Riemann vs. Lebesgue Integration: Theoretical & Practical Distinctions

  • Smooth & Piecewise Continuous Functions: For well-behaved functions like sin(x) and step functions, both approaches converge to the exact same value. Riemann integration is computationally faster because it only requires evaluating f(x) on a regular grid without calculating preimage measures.
  • Singular Functions (f(x) = 1/√x): The Riemann integral is technically an improper integral requiring limits. Lebesgue integration handles unbounded functions naturally through horizontal truncation, avoiding infinite spikes at boundary points.
  • Pathological Functions (The Dirichlet Function): The indicator function of rationals f(x) = 1ℚ(x) is not Riemann integrable because every subinterval contains both rationals and irrationals, fixing the upper Darboux sum at 1 and the lower Darboux sum at 0. In contrast, because the set of rationals is countable, its Lebesgue measure is μ(ℚ ∩ [0, 1]) = 0. The Lebesgue integral effortlessly evaluates to exactly 0:
    ∫[0, 1] 1ℚ dμ = 1 · μ(ℚ) + 0 · μ(ℝ ∖ ℚ) = 1(0) + 0(1) = 0.
